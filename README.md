# CodeVerse — Web Development Playground

## Run it
1. Extract this folder.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Use the sidebar to explore HTML, CSS, JavaScript topic cards.
4. Open Live Playground, choose a language tab, edit the starter code, and click **Run code**.

## Files
- `index.html` — page structure
- `style.css` — responsive dark cyberpunk styling
- `app.js` — library content, search, navigation, and live preview

## Notes
- Google Fonts needs an internet connection; system fonts are used as fallbacks.
- The playground runs user code in a sandboxed iframe. This is a learning starter, not a complete production-grade IDE.
- The libraries cover common core topics and examples; no single page can contain every current and future HTML, CSS, and JavaScript feature.
